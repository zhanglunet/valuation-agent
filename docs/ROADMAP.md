# Roadmap

## 1.0 已实现

- 离线 seed 数据闭环。
- 任意上市公司的公司名/简称/股票代码自动检索分析。
- 一个本地 seed 示例用于回归测试。
- 市值倒推股价。
- PE / PS 隐含倍数。
- 三情景分析。
- Markdown 报告。
- Hermes Skills 包装。
- 单元测试和集成测试。
